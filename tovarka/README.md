# Товарка

Учёт партий из Китая, склада, фото и прибыли. Одно приложение для телефона и ПК (PWA).

## Как считается

| Что | Формула |
|---|---|
| Курс юаня для выкупа | курс ЦБ + 0,5 ₽ (ЦБ подтягивается сам) |
| Карго | общий вес × 2,9 $/кг × 89,5 ₽ |
| Доставка по РФ | +2 000 ₽ на посылку |
| Логистика на 1 вещь | (карго + доставка РФ) делится по весу вещей |
| Себестоимость 1 шт | выкуп ¥ × курс юаня + доля логистики |

Вес вводить не нужно: он ставится по типу вещи (худи 0,8 кг, пуховик 1,5 кг…).
Таблица типов и все ставки меняются в «Настройках». Курсы запоминаются в каждой партии,
чтобы старые расчёты не менялись.

## Запуск

Нужен Python 3.10+.

- **Windows:** дважды кликни `run.bat`. Если Python не установлен — поставь с python.org и отметь галочку «Add python.exe to PATH».
- **Mac / Linux:** `./run.sh`

Браузер откроется сам, когда сервер будет готов (адрес — в чёрном окне). Окно не закрывай, пока пользуешься. Данные и фото хранятся в папке `data/`
(сделай её копию, чтобы не потерять).

С телефона в той же Wi-Fi можно открыть `http://IP-компьютера:8000`.
Установка иконкой на телефон требует HTTPS — это появится, когда приложение
переедет на сервер (этап 3). На ПК установка работает уже сейчас:
значок «Установить» в адресной строке Chrome/Edge.
