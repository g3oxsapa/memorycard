# Marginly — приложение

Интерфейс Marginly: партии, склад, заказы со статусами, прибыль. Один код для веба и Android.

- `src/store.js` — данные и расчёты (себестоимость, заказы, окупаемость, лимиты тарифа)
- `src/sync.js` — связь с сервером: данные на устройстве + очередь изменений, работает без сети
- `src/auth.js` — вход, регистрация, подтверждение почты, сброс пароля
- `src/orders.js` — заказы: Заказан → Отправлен → Продан / Отменён / Возврат
- `src/ui.js`, `src/app.js` — экраны и запуск

Сборка:

```
python build.py                                   # веб-версия → ../server/web
python build.py --android https://api.marginly.ru # Android → ../android/app/src/main/assets
```
